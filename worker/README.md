# Сервер напоминаний (Cloudflare Workers)

Бот пишет пользователю в чат накануне тренировки (по умолчанию в 20:00) и в день тренировки (в 09:00) по его часовому поясу. Дни и названия тренировок берутся из плана в мини-приложении. Бесплатного тарифа Cloudflare хватает.

## Установка через сайт Cloudflare
1. Зарегистрируйтесь на https://dash.cloudflare.com.
2. Storage & Databases → KV → Create: имя `REMINDERS`.
3. Compute (Workers) → Create → Hello World → Deploy. Затем Edit code, замените весь код содержимым `reminders.js` и нажмите Deploy.
4. В воркере: Settings → Bindings → Add → KV namespace, имя переменной `REMINDERS`, выберите созданное пространство.
5. Settings → Variables and Secrets:
   - `BOT_TOKEN`, тип Secret: токен бота из @BotFather;
   - `APP_URL`, тип Text: `https://timurr050.github.io/ai-trainer/`.
6. Settings → Trigger events → Add → Cron: `*/15 * * * *`.
7. (Сделано: воркер выкладывается сам через GitHub Actions, адрес https://ai-trainer.tim9728.workers.dev.) Скопируйте адрес воркера (`https://….workers.dev`) и впишите его в `REMIND_URL` в `src/app.js`, затем `python3 src/build.py`.

Проверка подписи Telegram (initData) не даёт чужим людям менять чужие напоминания.

## Админ-панель (с версии 3.6)

- Мини-приложение раз в день отправляет `action: "hello"`: воркер записывает пользователя в KV (`p<id>`, данные в metadata).
- В «Профиле» владелец нажимает «Стать администратором»: его ID сохраняется в KV под ключом `admin`, и воркер ставит вебхук бота на `/tg`. После этого кнопка больше никому не показывается. Можно также задать `ADMIN_IDS` в переменных воркера.
- Вебхук: бот отвечает на /start приветствием с кнопкой и отмечает тех, кто его заблокировал.
- Рассылка идёт частями по 40 сообщений за запрос (лимит бесплатного тарифа), приложение отправляет части по очереди.

## Админ-панель 2 (версия 3.7)

- Вкладки: Обзор (цифры и графики за 30 дней), Сообщения, Рассылка, Люди, Ещё.
- Сообщения пользователей боту сохраняются в KV `m<id>:<время>`; админу приходит уведомление с `#id<число>`, ответ на него свайпом уходит пользователю.
- Фото, присланное админом боту, сохраняется как `admin_photo` и может идти в рассылку.
- Рассылка по сегментам (`inSeg`), отложенные рассылки `bc<время>` отправляет cron партиями.
- Автосообщения: «давно не тренировался» (18:00 по времени пользователя) и рубежи 10/25/50/… тренировок; настройки в KV `cfg`.
- Источники: ссылки `t.me/<бот>?start=<метка>`, метка сохраняется в карточке пользователя.
- Выгрузка: CSV (открывается в Excel) приходит админу в чат через sendDocument.
- Бан: поле `x` в карточке, бот молчит, приложение показывает «Доступ ограничен».

## AI-тренер (чат)

Пользователь задаёт вопрос в чате с ботом или на экране «Спросить AI-тренера» в приложении. История общая, хранится в KV по ключу `c<id>` (последние 24 сообщения), лимит 20 вопросов в сутки на человека (админ без лимита). Под ответами-планами есть кнопка «PDF»: сервер собирает PDF (pdf-lib, шрифт DejaVu Sans с кириллицей) и присылает файлом в чат с ботом. Команда `/new` в боте начинает разговор заново.

- По умолчанию работает бесплатный Cloudflare Workers AI (`@cf/google/gemma-4-26b-a4b-it`, 10 000 нейронов в сутки, это несколько сотен ответов).
- Перейти на Claude: в `wrangler.toml` поставить `AI_PROVIDER = "claude"`, добавить секрет `ANTHROPIC_API_KEY` (Cloudflare → Workers → ai-trainer → Settings → Variables), модель можно сменить переменной `CLAUDE_MODEL`.
- После каждого деплоя GitHub Actions обновляет вебхук и задаёт тестовый вопрос: ответ и размер PDF видны в логе шага «Set webhook and test AI coach».
