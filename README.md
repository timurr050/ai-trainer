# AI-Тренер: мини-приложение для тренировок в Telegram

При первом входе приложение задаёт 5 вопросов: где человек тренируется (дома, на улице, в зале), какой инвентарь есть, цель, уровень, сколько тренировок в неделю и по сколько минут. По ответам оно составляет план на неделю и подбирает упражнения из библиотеки (80 упражнений с разметкой по инвентарю и группам мышц).

Экраны: **Тренер** (тренировка дня, план недели, конструктор «своей тренировки» по группам мышц), **Упражнения** (вся база из 900+ упражнений на русском с умным поиском по фразе вроде «бицепс с гантелями дома» и «Моей тренировкой» из выбранных упражнений), **Таймер**, **История**, **Прогресс** (тренировки по неделям, подходы по мышцам, рабочие веса и рекорды). История и прогресс начинаются с нуля и заполняются реальными тренировками. Данные хранятся на устройстве и в облаке Telegram (CloudStorage), так что видны и на других устройствах пользователя. Профиль меняется через ⚙️ на главном экране.

Подбор сейчас работает по правилам (без нейросети): учитывает инвентарь, место, уровень и цель. Подключить настоящую нейросеть можно позже, для этого нужен сервер.

## База упражнений
Кроме 80 упражнений, по которым составляется план, в каталоге есть вся открытая база [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (876 упражнений, общественное достояние, Unlicense) с фотографиями старта и финиша. Названия и техника переведены на русский и лежат в `tools/tr/`. Поиск понимает мышцы, инвентарь, место, уровень и тип нагрузки («растяжка спины для новичка», «ноги без инвентаря», «трицепс на блоке»), остальные слова ищет в названиях. Пересборка базы: `python3 tools/make_exdb.py`, затем `python3 src/build.py`.

**Сборка.** Правки делаются в `src/`, затем `python3 src/build.py`. Он создаёт `index.html` (лёгкая оболочка: при каждом открытии проверяет `version.txt` без кэша и загружает свежие `app.css` и `app.js`, поэтому обновления приходят в Telegram сразу, без ручного обновления страницы) и `standalone.html` (всё приложение одним файлом; для Netlify переименуйте его в `index.html`).

## Почему не SwiftUI

Telegram Mini App это веб-страница, которую Telegram открывает у себя внутри (WebView) на iPhone, Android и компьютере. SwiftUI-код Telegram запустить не может, поэтому приложение сделано на HTML/CSS/JS с официальным скриптом `telegram-web-app.js`. Благодаря ему оно берёт имя пользователя, красит шапку в чёрный, показывает системную кнопку «Назад», большую кнопку «Начать тренировку» внизу и вибрацию.

## Запуск в Telegram

### 1. Посмотреть локально
Откройте `index.html` в браузере, либо:
```
cd telegram-workout-app
python3 -m http.server 8080
```
и зайдите на http://localhost:8080.

### 2. Выложить в интернет по HTTPS
Telegram открывает только адреса `https://`. Самые простые бесплатные варианты:

- **Netlify Drop**: зайдите на https://app.netlify.com/drop и перетащите папку, в которой лежит только `standalone.html`, переименованный в `index.html`. Через несколько секунд получите адрес вида `https://имя.netlify.app`.
- **GitHub Pages**: создайте репозиторий, загрузите в него `index.html`, `app.css`, `app.js` и `version.txt`, затем Settings → Pages → Branch: `main` → Save. Адрес: `https://ваш-логин.github.io/репозиторий/`.
- **Vercel**: `npx vercel` в папке проекта.

Откройте полученный адрес в браузере и убедитесь, что приложение работает.

### 3. Создать бота
1. В Telegram найдите **@BotFather** (с синей галочкой).
2. Отправьте `/newbot`, введите название (например, «Лайм Фитнес») и username, оканчивающийся на `bot` (например, `lime_fitness_bot`).
3. BotFather пришлёт токен. Для этого приложения он не нужен, но храните его в секрете.

### 4. Подключить мини-приложение
Вариант А, кнопка меню (проще всего):
1. В @BotFather: `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → **Configure menu button**.
2. Пришлите HTTPS-адрес из шага 2, затем текст кнопки, например `Тренировки`.
3. Откройте своего бота: слева от поля ввода появится кнопка «Тренировки». Нажмите её.

Вариант Б, ссылка на приложение `t.me/бот/app`:
1. В @BotFather отправьте `/newapp`, выберите бота.
2. Введите название, описание, загрузите картинку 640×360 (GIF можно пропустить командой `/empty`).
3. Пришлите HTTPS-адрес и короткое имя, например `workout`.
4. Приложение будет открываться по ссылке `https://t.me/lime_fitness_bot/workout`, ею можно делиться.

Можно сделать оба варианта, они не мешают друг другу.

### 5. Как обновлять
Измените файлы и выложите их заново тем же способом (на Netlify перетащите папку в раздел Deploys, на GitHub Pages сделайте коммит). Адрес не меняется, Telegram сам подтянет новую версию. Если видите старую версию, закройте мини-приложение полностью и откройте снова.

### Отладка без деплоя (по желанию)
Чтобы смотреть изменения в Telegram сразу, пробросьте локальный сервер в интернет через туннель:
```
python3 -m http.server 8080
npx localtunnel --port 8080      # или: ngrok http 8080, или: cloudflared tunnel --url http://localhost:8080
```
Туннель выдаст временный `https://`-адрес, его можно временно указать в Menu Button. Для просмотра консоли: на Android включите в настройках Telegram «Отладку WebView» и откройте `chrome://inspect` на компьютере; на iPhone используйте Safari → Разработка; в Telegram Desktop включите отладку через Настройки → Продвинутые → Experimental settings → Enable webview inspecting.
